Cache percentage is cached input divided by total input, rounded to two decimal places. It is N/A when total input is zero. Output includes reasoning tokens.

Total API cost estimates what the recorded model tokens would cost through each model's default API provider. Each request uses the archived official rates for its exact model, processing tier and context length. Multiply uncached input, cached input and output by their respective USD rates per million tokens, divide by one million, and sum across requests. Apply separate cache-write rates when applicable. The archive records the rate verification date and any pricing tier assumptions. Unknown means no verified archived cost. The estimate excludes separately billed tools and taxes.
