# Inter

`inter-variable.woff2` is the Inter variable font from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/inter), retrieved
2026-11-11, losslessly repackaged as WOFF2 with FontTools. The upstream filename
is `Inter[opsz,wght].ttf`. It is redistributed
under the SIL Open Font License in `OFL.txt`. The page self-hosts it and makes no
runtime requests to Google Fonts. The favicon reuses ScummBench's existing
branding asset.
