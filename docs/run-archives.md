# Registered conversation archives

ScummBench registers verified AgentSCUMM archives while retaining their original
location and provenance. See [registered playthroughs](evaluation.md#registered-playthroughs)
for ownership, idempotence, privacy, and comparison limits.

## Token pricing

The result table uses each archive's recorded API-equivalent model-token cost,
official rate snapshot, context bands, cache accounting, and processing-tier
assumptions. Missing telemetry or pricing remains unknown. Registration does not
reprice a run or treat estimates as actual subscription charges. Separately
billed tools and taxes are excluded.
